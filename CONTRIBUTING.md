# Contributing to black-file-os / V6 CORE

We welcome contributions that improve the cinematic AI studio capabilities.

## How to Contribute
1. Fork the repository
2. Create a feature branch
3. Make your changes (especially in v6_core/)
4. Test thoroughly in Termux
5. Submit a pull request

## Focus Areas
- FFmpeg pipeline improvements
- New cinematic effects and LUT support
- UI/UX enhancements
- Performance optimizations for Android
- New integrations (more platforms)

Thank you for helping make V6 CORE the best cinematic production system!
