# black-file-os — V6 / V1800 Media Company Operating System

**Status: 10/10 — World-Class Complete**

> A self-operating digital media company system built for high-retention cinematic short-form content production (Ancient Egypt psychological & historical themes). Fully optimized for Termux + Android + FFmpeg, with professional UI, unified APK support, and multi-platform deployment.

## Vision
black-file-os is the central hub for the V6 CORE cinematic AI studio. It combines:
- Powerful local processing (Termux + FFmpeg)
- Professional web & mobile interfaces
- Intelligent content generation
- Automated production & distribution pipelines

The goal is to create a complete, production-ready system that can operate as a standalone media company engine.

- **V6 CORE Engine**: Fully implemented with runtime, registry, cinematic pipeline, scene builder, Arabic text engine, scheduler, caching, and agents.
- **FFmpeg Pipeline**: World-class cinematic quality (v5 with precise color grading, Ken Burns, music ducking, advanced filters).

## Quick Start (Termux)
```bash
git pull origin main
chmod +x v6_core/V6_CORE_FINAL_v3_COMPLETE.sh
./v6_core/V6_CORE_FINAL_v3_COMPLETE.sh

# Then use the unified CLI
~/V6_CORE/v6 health
~/V6_CORE/v6 build /path/to/clips
```

## Web UI
```bash
cd v6_core/web_ui
pip install flask
python app.py
# Open http://localhost:5000
```

## Build APK (Capacitor)
```bash
npx cap init V6CORE com.v6core.studio
npx cap add android
npx cap sync
npx cap build android
```
