# تعميق في خوارزميات معالجة الصوت في V6 CORE

## 1. Sidechain Compression (للـ Music Ducking)

**الخوارزمية**: 
يستخدم FFmpeg `sidechaincompress` والتي تعتمد على **Dynamic Range Compression** مع إشارة تحكم خارجية (الـ Voice).

**المعادلة الأساسية**:
```
output = input * (threshold / |sidechain_signal|)^(1/ratio)   (عندما يتجاوز الـ sidechain الـ threshold)
```

**المعاملات المستخدمة في v7**:
- threshold=0.05 ~ 0.08
- ratio=15:1 ~ 16:1 (ضغط قوي)
- attack=0.004~0.008 ثانية (سريع جداً)
- release=0.7~0.8 ثانية (سلس)
- makeup=1.2~1.3 (تعويض الكسب)

**لماذا هذه القيم؟**
- نسبة ضغط عالية = الموسيقى تنخفض بشكل ملحوظ عند وجود صوت.
- هجوم سريع = لا يُفقد بداية الكلمات.
- إصدار متوسط = انتقال طبيعي بين الصوت والموسيقى.

## 2. loudnorm (EBU R128 Normalization)

**المعيار**: BS.1770-4

**المكونات**:
- **Integrated Loudness (I)**: متوسط مستوى الصوت على كامل المقطع (الهدف -16 LUFS).
- **True Peak (TP)**: أعلى قمة حقيقية (الهدف -1.5 dBTP).
- **Loudness Range (LRA)**: نطاق الديناميك (الهدف 11 LU).

**الخوارزمية**:
تقيس FFmpeg مستوى الصوت باستخدام مرشحات K-weighting ثم تطبق كسب ثابت للوصول إلى الهدف.

**الفائدة**:
يضمن مستوى صوت موحد عبر جميع الفيديوهات (مهم جداً للـ Shorts).

## 3. Compand Filter

**الخوارزمية**:
ضغط/توسيع الديناميك رينج باستخدام منحنى نقاط (points).

**مثال في v7**:
```
compand=attacks=0.01:decays=0.2:points=-80/-80|-20/-20|0/-15|20/-15
```

- يقلل من الديناميك في المناطق الهادئة والعالية.
- يجعل الصوت أكثر "حضوراً" ووضوحاً.

## 4. FFT-based Noise Reduction (afftdn)

**الخوارزمية**:
- تحول الصوت إلى مجال التردد باستخدام FFT.
- تقدر الضوضاء في كل تردد.
- تطرح الضوضاء مع الحفاظ على الإشارة المفيدة.

**المعامل nf=-25**:
قوة تقليل الضوضاء (أعلى = أقوى تقليل، لكن قد يؤثر على الجودة).

## 5. Stereo Tools & Spatial Processing

**stereotools**:
- يستخدم تقنيات M/S (Mid/Side) لتوسيع أو تضييق مجال الستيريو.
- يعطي إحساساً بـ "الغمر" دون الحاجة إلى صوت محيطي حقيقي.
