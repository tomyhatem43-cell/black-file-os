# أدوات الاختبار و CI/CD في V6 CORE

## GitHub Actions (مُفعّل)
يوجد workflow في `.github/workflows/ci.yml` يقوم بـ:
- فحص ShellCheck على جميع السكريبتات.
- التحقق من صحة صيغة Bash.
- التحقق من صيغة Python (إن وجد).

## كيفية التوسع
يمكن إضافة:
- اختبارات وحدة للسكريبتات.
- اختبارات تكاملية لخط أنابيب FFmpeg.
- نشر تلقائي إلى Replit عند الـ push.

## التوصيات
- شغّل الـ CI على كل push للحفاظ على جودة الكود.
- أضف اختبارات FFmpeg باستخدام ملفات عينة صغيرة.
