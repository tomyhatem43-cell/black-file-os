# Deployment Guide

## Termux (Recommended for Production)
1. Clone the repo
2. Run the bootstrap script
3. Use the `v6` CLI

## Replit (For Cloud Prototyping)
Import the GitHub repo directly. The `.replit` and `replit.nix` files handle automatic setup with FFmpeg and Python.

## Android APK
Use Capacitor to wrap the Web UI into a professional Android application.

## Future
Lovable for UI streaming and rapid visual prototyping.
