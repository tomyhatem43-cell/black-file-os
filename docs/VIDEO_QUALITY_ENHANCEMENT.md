# تحسين جودة الفيديو في V6 CORE (الإصدار v10)

## التقنيات المستخدمة لتحسين الجودة

### 1. تصفية الضوضاء المتقدمة (nlmeans)
- خوارزمية Non-Local Means لإزالة الضوضاء مع الحفاظ على التفاصيل.

### 2. التوضيح (Unsharp Masking)
- تحسين الحدة دون مبالغة.

### 3. التحجيم عالي الجودة (Lanczos)
- أفضل خوارزمية للـ scaling مع الحفاظ على الحدة.

### 4. تحسين التدرج اللوني والتباين
- تعديلات دقيقة على eq للحصول على مظهر سينمائي غني.

### 5. محاكاة حبيبات الفيلم
- إضافة noise خفيف لمظهر عضوي.

## الإعدادات الموصى بها (v10)
```bash
-vf "scale=1080:1920:flags=lanczos, nlmeans=8:5:3, unsharp=5:5:1.2, eq=brightness=-0.08:contrast=1.15:saturation=0.9, noise=alls=6:allf=t+u"
-c:v libx264 -preset slow -crf 18
```

## التكامل
يعمل مع:
- GPU Acceleration (v9)
- Audio Mixing المتقدم (v7 + v8)
- LUTs و Color Grading

**النتيجة**: جودة بصرية أعلى بكثير مع الحفاظ على الأداء المناسب لـ Termux.
